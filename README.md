Stradivarius Mega Silkway Project

This repository contains a multi-page(6 pages) HTML and CSS website developed as a student project for the Web Technologies course at Astana IT University.


Team Members:

Auyezkhan Alina

Kharagussova Zhamilya

1. Stylesheet Integration & Organization
External stylesheets linked correctly across all HTML pages (base.css, alina.css, zhamilya.css)

Universal box-sizing reset applied (* { box-sizing: border-box; })

Code passes the W3C CSS Validator with zero errors

2. Styling & Custom Properties
CSS variables defined in :root for color palette, spacing, and font families

Distinct typography hierarchy established using display (Georgia) and body (Helvetica Neue) fonts

Consistent styling applied to headings, links, blockquotes, and tables

3. Layout & Modern CSS Techniques
Flexbox utilized for navigation bars (#site-nav), headers, and form containers

CSS Grid implemented for multi-column structures (.categories-grid, .material-card)

Responsive layout handling via minmax() and auto-fit configurations

4. Selectors & Interactive States
Element, class, and attribute selectors properly structured

Interactive pseudo-classes (:hover, :focus) implemented for buttons, navigation links, and cards

Advanced selectors utilized (such as :first-child, adjacent sibling selectors +, and structural pseudo-classes)

5. Visual Enhancements & Positioning
Smooth transitions applied for hover and focus state changes

Fixed positioning utilized for auxiliary UI components (.fixed-contact)

Absolute positioning used for dynamic labeling elements (.badge-new)


Technical Standards

Developed using pure semantic HTML5 without external JavaScript.

All files pass the W3C Markup Validation Service with zero errors.
